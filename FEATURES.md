### Engine Precedence, Exclusions, Prompt-First Crash Fallback & CLI Parity (`v0.6.1`)
- **What it does:** Evaluates `incompatibleEngineVersions` SemVer, wildcard (`0.2.x`, `0.*`), and range (`>=0.5.0 <0.5.2`) exclusions (`EngineCompatibilityEvaluator`), selects the latest `.ready`-gated `re*` candidate honoring `pinnedEngineVersions` (`moduleId` -> `engineId` -> aliases) and `-hf.<n>` ranking, relaunches abnormally terminated children onto bundled/target fallbacks after user prompt (`TryCrashFallbackRelaunchAsync`) with closest checkpoint/quicksave location (`SessionRecoveryLocator`), binds `LauncherJobObjectGuard` strictly on `--wait`, routes `>= 0.6.1` CLI flags (`--rom`, `--disc`, `--demo-cart`, `--window`, `--overscan`, `--fps-mode`, `--open-settings`, `--show-fps`, `--force-zero-rwx`, `--fast-forward`, `--ui-text-scale`, optional-value `--require-backend [<id>]`), quiets `--demo-cart` idle audio, and suppresses idle `settings.controls.json` disk churn (`SerializeDirtyCheckJson()`).

### Execution Resilience, Safe Mode & Split-Domain Settings (`v0.6.0`)
- **What it does:** Tracks boot completion via atomic `<dataDir>\booting.sentinel` PID checks (`BootCrashSentinel`), activating in-memory Safe Mode after a prior dirty crash (disabling `.re*` packs, HD texture overrides, and falling back Vulkan/DirectX 12 to OpenGL without modifying saved disk video/audio settings) until frame `1` renders or `--safe-mode-reset` / UI reset runs. Validates physical RAM headroom (`>= 512 MiB` free and `<= 75%` available) in `MediaRamPreloader` before pinning ROM/disc payloads in RAM, enforces clean-room AOT vs Tier 3 JIT rules (`ExecutionTierPolicy`, keeping `interpreterOracle` strictly CLI-only), and splits runtime state cleanly across `settings.json` (`v2` core), `settings.video.json`, `settings.audio.json`, and `settings.controls.json` with automatic `v1 -> v2` snapshots in `data\config_history\`, corrupt JSON isolation in `data\quarantine\`, and `.bak` recovery.
- **Entry Points:** [`BootCrashSentinel.cs`](Dev/src/reEngine.Core/Execution/BootCrashSentinel.cs), [`MediaRamPreloader.cs`](Dev/src/reEngine.Core/Execution/MediaRamPreloader.cs), [`ExecutionTierPolicy.cs`](Dev/src/reEngine.Core/Execution/ExecutionTierPolicy.cs), [`SettingsDomainStore.cs`](Dev/src/reEngine.Core/Updates/SettingsDomainStore.cs), [`ReEngineDomainSettings.cs`](Dev/src/reEngine.Core/Updates/ReEngineDomainSettings.cs), [`HostSettingsStore.cs`](Dev/src/reEngine.Host/Settings/HostSettingsStore.cs), [`HostSessionRuntimeBridge.cs`](Dev/src/reEngine.Host/Core/HostSessionRuntimeBridge.cs), [`SystemTabView.cs`](Dev/src/reEngine.Host/Ui/SystemTabView.cs)
- **Extension Point / What to Touch:** Add domain properties in `ReEngineDomainSettings.cs` and invariants in `SettingsDomainStore.cs`; `[JsonExtensionData]` preserves unknown keys automatically.
- **Tests:** [`HostExecutionResilienceAndSettingsSplitTests.cs`](Dev/tests/reEngine.Tests/HostExecutionResilienceAndSettingsSplitTests.cs)
