## Capability Details

### 5-Backend `reEngine.Host.dll`, HD Texture Packs & Native OS Audio
- **What it does:** Initializes SDL3 video and gamepad subsystems independently of `SDL_AUDIO_DRIVER` (pinning `wasapi` on Windows prior to `SDL_InitSubSystem(InitAudio)`), creates native swapchain contexts for `OpenGL 3.3+` (`Gl33Presenter`), `Vulkan 1.3+` (`VulkanPresenter`), and `DirectX 12` (`D3d12Presenter`) without conflicting `SDL_CreateRenderer` calls, provides a deterministic `16px`-band `ParallelCpuPresenter` matching `Software` SHA-256 bit-for-bit at `1x`, indexes path-contained `<dataDir>\hdpacks\` PNG overrides by `(clutSha256Hex, rectSha256Hex)`, supports fullscreen rendering, and returns `ExitCode = 6` (`BackendUnavailableException`) when `--require-backend` is unsupported.
- **Entry Points:** [`Sdl3HostWindow.cs`](Dev/src/reEngine.Host/Core/Sdl3HostWindow.cs), [`NativeAudioDriverSelector.cs`](Dev/src/reEngine.Host/Core/NativeAudioDriverSelector.cs), [`Gl33Presenter.cs`](Dev/src/reEngine.Host/Rendering/Gl33Presenter.cs), [`VulkanPresenter.cs`](Dev/src/reEngine.Host/Rendering/VulkanPresenter.cs), [`D3d12Presenter.cs`](Dev/src/reEngine.Host/Rendering/D3d12Presenter.cs), [`ParallelCpuPresenter.cs`](Dev/src/reEngine.Host/Rendering/ParallelCpuPresenter.cs), [`HdPackResolver.cs`](Dev/src/reEngine.Host/Rendering/HdPackResolver.cs)
- **Tests:** [`HostMultiBackendAndAudioTests.cs`](Dev/tests/reEngine.Tests/HostMultiBackendAndAudioTests.cs), [`HostSurfaceAndInputTests.cs`](Dev/tests/reEngine.Tests/HostSurfaceAndInputTests.cs), [`HostReleaseAutomationStripTests.cs`](Dev/tests/reEngine.Tests/HostReleaseAutomationStripTests.cs)

### 3-Slot Multi-Bind Input, Xbox/HID Gamepads, Dynamic `Controls` & Touch Contracts
- **What it does:** Combines 3-slot `[1st, 2nd, 3rd]` simultaneous KBM + mouse/wheel bindings (`1001..1007`) with repeat filtering and single-edge sub-tick isolation (`HostMultiBindRegistry`), polls Xbox and open-standard HID SDL3 gamepads (`2001..2032`, `0.15f` deadzone, `0.40f` trigger threshold, hot-plug reconnect, dual-motor rumble) via `Sdl3GamepadProvider`, exposes cross-platform `IHostInputProvider` / `HostTouchOverlayView` contracts, and renders dynamic module `ControlOptions` (`ControlsTabView`) plus an interactive 5-column `Action | 1st | 2nd | 3rd | Gamepad` matrix (`KeybindsTabView`) inside the `F1` drawer (`F1SettingsDrawerView`).
- **Entry Points:** [`HostMultiBindRegistry.cs`](Dev/src/reEngine.Host/Input/HostMultiBindRegistry.cs), [`Sdl3GamepadProvider.cs`](Dev/src/reEngine.Host/Input/Sdl3GamepadProvider.cs), [`ControlsTabView.cs`](Dev/src/reEngine.Host/Ui/ControlsTabView.cs), [`KeybindsTabView.cs`](Dev/src/reEngine.Host/Ui/KeybindsTabView.cs), [`HostTouchOverlayView.cs`](Dev/src/reEngine.Host/Ui/HostTouchOverlayView.cs), [`F1SettingsDrawerView.cs`](Dev/src/reEngine.Host/Ui/F1SettingsDrawerView.cs)
- **Tests:** [`HostMultiBindInputAndTouchTests.cs`](Dev/tests/reEngine.Tests/HostMultiBindInputAndTouchTests.cs), [`HostUiDrawerAndGateTests.cs`](Dev/tests/reEngine.Tests/HostUiDrawerAndGateTests.cs)

### Interactive `.decomp` Bring-Up Runner, Suite Media Discovery & `--verify-module`
- **What it does:** Launches Explorer-opened `.decomp` files straight onto the `Bring-Up` shelf (`ReEngineMainForm.Decomp.cs`) with `D0..D5` stage controls, live logs, and automatic root-tree media search (`SuiteMediaTreeWalker`), opens `MissingMediaPromptDialog` defaulting to use-in-place with opt-in `.cue`/`.bin` staging into `data\rom\`, validates canonical `D4_CleanSource` (`D4_FunctionalRewrite` read-alias) in `DecompD4StrictnessValidator`, and exposes dual-mode `--verify-module [--json] [--require-media]` via `PackageVerificationService`.
- **Entry Points:** [`ReEngineMainForm.Decomp.cs`](Dev/src/reEngine.App/ReEngineMainForm.Decomp.cs), [`BringUpShelfPanel.cs`](Dev/src/reEngine.App/Ui/BringUpShelfPanel.cs), [`MissingMediaPromptDialog.cs`](Dev/src/reEngine.App/Ui/MissingMediaPromptDialog.cs), [`SuiteMediaTreeWalker.cs`](Dev/src/reEngine.Core/Decomp/SuiteMediaTreeWalker.cs), [`PackageVerificationService.cs`](Dev/src/reEngine.Core/Decomp/PackageVerificationService.cs), [`DecompD4StrictnessValidator.cs`](Dev/src/reEngine.Core/Decomp/DecompD4StrictnessValidator.cs)
- **Tests:** [`MediaTreeWalkerAndVerifyModuleTests.cs`](Dev/tests/reEngine.Tests/MediaTreeWalkerAndVerifyModuleTests.cs), [`DecompProviderAndD4ValidatorTests.cs`](Dev/tests/reEngine.Tests/DecompProviderAndD4ValidatorTests.cs), [`DecompAndToolchainTests.cs`](Dev/tests/reEngine.Tests/DecompAndToolchainTests.cs)

### Frontend `--wait` / `--fullscreen` / `--save-dir` Bridge, Bounded Shutdown & 5-Backend Library UI
- **What it does:** Upgrades `LibraryShelfPanel` with all 5 Windows backends (`opengl`, `vulkan`, `directx`, `parallelCpu`, `software`), `Fullscreen` toggle, and **Verify Package...** button; routes synchronous frontend launches (`--open --wait --fullscreen --save-dir --audio-driver`) cleanly through `RecompLaunchCoordinator` and `GracefulProcessTreeShutdown` (posting `WM_CLOSE` up to `--shutdown-timeout-ms` `3000` ms so saves flush before teardown), while keeping detached interactive child windows alive when `--wait` is omitted.
- **Entry Points:** [`LibraryShelfPanel.cs`](Dev/src/reEngine.App/Ui/LibraryShelfPanel.cs), [`RecompLaunchCoordinator.cs`](Dev/src/reEngine.App/RecompLaunchCoordinator.cs), [`RecompLaunchPlanBuilder.cs`](Dev/src/reEngine.App/RecompLaunchPlanBuilder.cs), [`GracefulProcessTreeShutdown.cs`](Dev/src/reEngine.App/GracefulProcessTreeShutdown.cs), [`LauncherArgsHelper.cs`](Dev/src/reEngine.Launcher/LauncherArgsHelper.cs)
- **Tests:** [`SyncWaitShutdownAndDecompUiTests.cs`](Dev/tests/reEngine.Tests/SyncWaitShutdownAndDecompUiTests.cs), [`LauncherAndLaunchPlanTests.cs`](Dev/tests/reEngine.Tests/LauncherAndLaunchPlanTests.cs), [`SettingsMigrationAndLaunchTests.cs`](Dev/tests/reEngine.Tests/SettingsMigrationAndLaunchTests.cs), [`run_stage2_sandbox_e2e.ps1`](Dev/scripts/run_stage2_sandbox_e2e.ps1)

### Resumable Updates, Installer Preservation & Side-by-Side Resolution
- **What it does:** Keeps `AllowAutoStart = false`, resolves bidirectional aliases (`reSlate`/`reStation`, `reCartOne`/`reNes`, `reCart64`/`re64`, `reBlast16`/`reGenesis`), sorts interactive Setup paths cleanly into `<parent>\reEngine\`, preserves `v0.4.0` `settings.json` keys with `.bak` recovery, sweeps installed tracks (`UpdateCoordinator`), and verifies updates with SSRF and Zip-Slip checks (`UpdatePackageApplier`).
- **Entry Points:** [`EngineVersionResolver.cs`](Dev/src/reEngine.Core/Resolution/EngineVersionResolver.cs), [`UpdatePackageApplier.cs`](Dev/src/reEngine.Core/Updates/UpdatePackageApplier.cs), [`UpdateCoordinator.cs`](Dev/src/reEngine.Core/Updates/UpdateCoordinator.cs), [`LegacyMigrationHelper.cs`](Dev/src/reEngine.Installer/LegacyMigrationHelper.cs)
- **Tests:** [`UpdateStagingAndTracksTests.cs`](Dev/tests/reEngine.Tests/UpdateStagingAndTracksTests.cs), [`InstallerAndAppStatusTests.cs`](Dev/tests/reEngine.Tests/InstallerAndAppStatusTests.cs), [`InstallerWizardAutoSortTests.cs`](Dev/tests/reEngine.Tests/InstallerWizardAutoSortTests.cs)
