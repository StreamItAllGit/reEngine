## Capability Details

### `HostViewportGeometry`, 5-Backend Presenters, GL Readback Sync & Native Audio
- **What it does:** Computes aspect-locked destination rects across all 5 `HostAspectRatioMode` presets (`nativePar`, `fourByThree`, `squareInteger`, `nativeFit`, `horPlus16By9`), bounded source edge trimming (`HostOverscanCrop`), `Surface0` (`#0E0E10`) margin fills, and inverse normalized content pointer mapping (`TryMapWindowToContentNormalized`) across `OpenGL 3.3+` (`Gl33Presenter`), `Vulkan 1.3+` (`VulkanPresenter`), `DirectX 12` (`D3d12Presenter`), `16px`-band `ParallelCpuPresenter`, and `Software`. Guards `Gl33Presenter` against `0x0` minimized framebuffers and incomplete FBOs (`0x8CD5`), exposes `IHostGraphicsContext` `OwnerThreadId`, owner-thread-guarded `TryReadSurfaceRect` (`glReadPixels` without Y-flip inversion), and `FlushAndSyncForSnapshot()` invoked before `F5` QuickSave and teardown (`Sdl3HostWindow.CloseWindowResources`), supports live `SDL_SetWindowFullscreen`, indexes path-contained `<dataDir>\hdpacks\` PNG overrides, pins native OS audio (`wasapi` on Windows before `InitAudio`), and returns `ExitCode = 6` (`BackendUnavailableException`) when `--require-backend` is unsupported.
- **Entry Points:** [`HostViewportGeometry.cs`](Dev/src/reEngine.Host/Core/HostViewportGeometry.cs), [`Sdl3HostWindow.cs`](Dev/src/reEngine.Host/Core/Sdl3HostWindow.cs), [`Gl33Presenter.cs`](Dev/src/reEngine.Host/Rendering/Gl33Presenter.cs), [`VulkanPresenter.cs`](Dev/src/reEngine.Host/Rendering/VulkanPresenter.cs), [`D3d12Presenter.cs`](Dev/src/reEngine.Host/Rendering/D3d12Presenter.cs), [`ParallelCpuPresenter.cs`](Dev/src/reEngine.Host/Rendering/ParallelCpuPresenter.cs), [`HdPackResolver.cs`](Dev/src/reEngine.Host/Rendering/HdPackResolver.cs), [`NativeAudioDriverSelector.cs`](Dev/src/reEngine.Host/Core/NativeAudioDriverSelector.cs)
- **Tests:** [`HostViewportGeometryAndPresentersTests.cs`](Dev/tests/reEngine.Tests/HostViewportGeometryAndPresentersTests.cs), [`HostMultiBackendAndAudioTests.cs`](Dev/tests/reEngine.Tests/HostMultiBackendAndAudioTests.cs), [`HostSurfaceAndInputTests.cs`](Dev/tests/reEngine.Tests/HostSurfaceAndInputTests.cs), [`HostReleaseAutomationStripTests.cs`](Dev/tests/reEngine.Tests/HostReleaseAutomationStripTests.cs)

### 4-Port SDL3 Gamepads, 3-Tier Input (`settings.controls.json`) & Interactive `F1` Drawer
- **What it does:** Polls up to 4 hot-pluggable SDL3 controllers (`PadPorts[0..3]`) with `0.15f` deadzone, `0.40f` trigger threshold, and per-port rumble (`Sdl3GamepadProvider`), persists all 3 rebindable control tiers (`globalController` / `Global 1:1`, `perGameController` / `Game 1:1`, `perGameModern` / `Modern PC`) inside `settings.controls.json` (`HostControlTierStore`) with duplicate and hidden-slot collision guards, isolates Menu `D-Pad` and `Left Stick` navigation independent of Free-Roam bindings, combines 3-slot `[1st, 2nd, 3rd]` simultaneous KBM + mouse/wheel bindings (`1001..1007`) and gamepad codes (`2001..2032`) via `HostMultiBindRegistry`, dispatches live `IHostSessionEventCallbacks` from interactive `F1` drawer controls (`AspectRatioMode`, `OverscanCropPx`, `FastForward`, `CutsceneSkip`, `Controls`, 3-tier `Keybinds`, and `ExtraRows`), handles `F5`/`F9`/`F11`/`Alt+Enter` hotkeys, keeps SDL events pumping during startup/AOT waits, and decouples automation via `IHostAutomationBridge`.
- **Entry Points:** [`Sdl3GamepadProvider.cs`](Dev/src/reEngine.Host/Input/Sdl3GamepadProvider.cs), [`HostControlTierStore.cs`](Dev/src/reEngine.Host/Input/HostControlTierStore.cs), [`HostInputMapper.cs`](Dev/src/reEngine.Host/Input/HostInputMapper.cs), [`HostMultiBindRegistry.cs`](Dev/src/reEngine.Host/Input/HostMultiBindRegistry.cs), [`F1SettingsDrawerView.cs`](Dev/src/reEngine.Host/Ui/F1SettingsDrawerView.cs), [`F1DrawerTabRenderers.cs`](Dev/src/reEngine.Host/Ui/F1DrawerTabRenderers.cs), [`ControlsTabView.cs`](Dev/src/reEngine.Host/Ui/ControlsTabView.cs), [`KeybindsTabView.cs`](Dev/src/reEngine.Host/Ui/KeybindsTabView.cs), [`HostTouchOverlayView.cs`](Dev/src/reEngine.Host/Ui/HostTouchOverlayView.cs)
- **Tests:** [`HostMultiPortInputAndHotkeysTests.cs`](Dev/tests/reEngine.Tests/HostMultiPortInputAndHotkeysTests.cs), [`HostMultiBindInputAndTouchTests.cs`](Dev/tests/reEngine.Tests/HostMultiBindInputAndTouchTests.cs), [`HostUiDrawerAndGateTests.cs`](Dev/tests/reEngine.Tests/HostUiDrawerAndGateTests.cs)

### Interactive `.decomp` Bring-Up Runner, `.fds` Media Discovery & `--verify-module`
- **What it does:** Launches Explorer-opened `.decomp` files straight onto the `Bring-Up` shelf (`ReEngineMainForm.Decomp.cs`) with `D0..D5` stage controls, live logs, and automatic root-tree media search (`SuiteMediaTreeWalker`, including `.fds` Famicom Disk System parity alongside `.nes` and optical disc formats), opens `MissingMediaPromptDialog` defaulting to use-in-place with opt-in `.cue`/`.bin` staging into `data\rom\`, enforces canonical `D4_CleanSource` (`D4_FunctionalRewrite` read-alias) and `.fds` clean-room rejection in `DecompD4StrictnessValidator` / `DecompPipelineCoordinator`, and exposes dual-mode `--verify-module [--json] [--require-media]` via `PackageVerificationService`.
- **Entry Points:** [`ReEngineMainForm.Decomp.cs`](Dev/src/reEngine.App/ReEngineMainForm.Decomp.cs), [`BringUpShelfPanel.cs`](Dev/src/reEngine.App/Ui/BringUpShelfPanel.cs), [`MissingMediaPromptDialog.cs`](Dev/src/reEngine.App/Ui/MissingMediaPromptDialog.cs), [`SuiteMediaTreeWalker.cs`](Dev/src/reEngine.Core/Decomp/SuiteMediaTreeWalker.cs), [`PackageVerificationService.cs`](Dev/src/reEngine.Core/Decomp/PackageVerificationService.cs), [`DecompD4StrictnessValidator.cs`](Dev/src/reEngine.Core/Decomp/DecompD4StrictnessValidator.cs)

### Frontend `--wait` / `--aspect-mode` / `hostProtocolVersion` Bridge & 5-Backend Library UI
- **What it does:** Upgrades `LibraryShelfPanel` with all 5 Windows backends (`opengl`, `vulkan`, `directx`, `parallelCpu`, `software`), `Fullscreen` toggle, and **Verify Package...** button; routes synchronous frontend launches (`--open --wait --fullscreen --save-dir --audio-driver --aspect-mode`) cleanly through `RecompLaunchCoordinator`, `RecompLaunchPlanBuilder` (forwarding CLI flags to engines declaring `hostProtocolVersion >= 0.3.0` or `minSuiteVersion >= 0.3.0`, including `reCart v0.1.0`), `LauncherArgsHelper` (`--aspect-mode` verbatim `ValueOptions` passthrough), and `GracefulProcessTreeShutdown` (posting `WM_CLOSE` up to `--shutdown-timeout-ms` `3000` ms so saves flush before teardown), while keeping detached interactive child windows alive when `--wait` is omitted.
- **Entry Points:** [`LibraryShelfPanel.cs`](Dev/src/reEngine.App/Ui/LibraryShelfPanel.cs), [`RecompLaunchCoordinator.cs`](Dev/src/reEngine.App/RecompLaunchCoordinator.cs), [`RecompLaunchPlanBuilder.cs`](Dev/src/reEngine.App/RecompLaunchPlanBuilder.cs), [`GracefulProcessTreeShutdown.cs`](Dev/src/reEngine.App/GracefulProcessTreeShutdown.cs), [`LauncherArgsHelper.cs`](Dev/src/reEngine.Launcher/LauncherArgsHelper.cs)

### 3-Way Aliases, `-hf.<n>` SemVer, Installer (`"suiteId": "reEngine"`) & Dual-Binary `ExitCode = 2`
- **What it does:** Keeps `AllowAutoStart = false`, resolves 3-way aliases (`reCart`/`reCartOne`/`reNes`) alongside `reSlate`/`reStation`, `reCart64`/`re64`, and `reBlast16`/`reGenesis`, fixes `SemVer.CompareTo` to rank `-hf.<n>` hotfixes strictly above stable releases while preserving `.ready` enforcement on `0.3.0+` and `0.3.0-hf.<n>`, enables `UpdateCoordinator` hotfix discovery with SSRF and Zip-Slip checks (`UpdatePackageApplier`), migrates `installer.manifest.json` to `"suiteId": "reEngine"` (`Foundation v0.5.2`), sorts interactive Setup paths into `<parent>\reEngine\`, preserves `v0.4.0` + `v0.5.0` `settings.json` keys (`aspectRatioMode`, `overscanCropPx`, `isFastForwardEnabled`) with `.bak` recovery, and enforces **Dual-Binary Release `ExitCode = 2`** whenever `--automation-port` is passed to Release `reEngine.exe` or Release `reEngine-Setup-v0.5.0-win-x64.exe`.
