# Changelog

All notable changes to **`reEngine`** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.6.1] - 2026-11-20

### Added
- **Scaled Legible Overlay Text, Full Tab Names & Complete `0.x` Drawer Controls (`reEngine.Host`):** Added `HostOverlayTextRenderer` (`BaseScale = 1.45x` default legibility multiplied by live `uiTextScale` `0.75x–2.0x`), expanded `F1` drawer tabs to full clear titles (`Video`, `Audio`, `Controls`, `Keybinds`, `System`, `Media`) with dynamic drawer widths (`430–780px`) and per-tab scrolling, added `8x` internal resolution scale (including WinForms `LibraryShelfPanel`), `Framerate` (`Original`/`Enhanced` + `defaultFramerateMode`) and `Target FPS` (`30`, `60`, `120`, `144`, `240`, `Max`), right-click defaults reset on `Aspect`, `Overscan` (`0px`/`8px`/`16px`), and `UI Text Scale`, live `Audio` master volume stepper, `System` controls (`Quick Save (F5)`, `Quick Load (F9)`, `Fast-Forward (F6)` + `FF Speed: 2x/3x/4x`, `Skip Cutscene (F7)`, `Runtime Logging` [`shouldEnableRuntimeLogs`], `Clean-Capture Mode` [`isCleanCaptureModeEnabled`], **`Quit Game`**), and `Media` Win32 native pickers (`Change Media...` / `Load .recomp...`).
- **Rebindable Host Actions (`HostActionBindingSet`), `menuControllerChord`, Unbound-`Tab` Fast-Forward & Relative Mouse Capture:** Split all 8 rebindable host actions (`toggleMenu`, `toggleHud`, `quickSave`, `quickLoad`, `fastForward`, `cutsceneSkip`, `toggleFullscreen`, `takeScreenshot`) into `hostActionBindings` inside `settings.controls.json` alongside game bindings in `KeybindsTabView` with cross-tier collision blocking, added unbound-`Tab` hold Fast-Forward, customizable `menuControllerChord` (`L3 + R3`, `Select + Start`, `Guide`, `None`), `Modern WASD + Mouse` (`controlMode`) with `Mouse Sensitivity` stepper (`0.25x–3.0x`) and deterministic `HostRelativeMouseController` (`SDL_SetWindowRelativeMouseMode`), plus `SDL_EVENT_DROP_FILE` drag-and-drop and live `TrySwitchBackend` switching in `Sdl3HostWindow`.
- **Full-Screen Glass Media Gate, Responsive AOT Compile Overlay, `F3` Badges & `100%` Controller Nav:** Upgraded `FirstRunMediaGateView` to a full-screen Deep Slate Glass drop/picker gate with quiet-idle `Launch Demo / Test Cart` (zero `"Continue Session"` bypass) backed by zero-WinForms `HostNativeFileDialog` (`comdlg32.dll`), added `HostAotCompileOverlayView` (`"Preparing Native Module..."` at `~60 Hz`), added `F3HudOverlayView` cadence (`[ORIG]`/`[ENH]`/`[MAX]`) and `[FF <N>x]` badges with Clean-Capture suppression, and added `HostDrawerControllerNav` (`D-Pad`/Left Stick/`LB`/`RB`/`A`/`B`/`X`-`Y`) across both `F1` drawer and Media Gate.
- **Engine Precedence, Incompatibility Rules, Crash Recovery & Unified CLI/Launcher Contract (`reEngine.Core` / `App` / `Launcher`):** Added `EngineCompatibilityEvaluator` (`incompatibleEngineVersions` SemVer, wildcard `0.2.x`/`0.*`, and comparator ranges), latest-by-default `.ready` engine resolution with `pinnedEngineVersions` (`moduleId` -> `engineId` -> alias) precedence and `-hf.<n>` ranking, prompt-first in-session crash fallback (`TryCrashFallbackRelaunchAsync`) + `SessionRecoveryLocator` closest checkpoint/quicksave locator, `LauncherJobObjectGuard` attached strictly on synchronous `--wait`, and unified CLI/routing flags (`--rom`, `--disc`, `--demo-cart`, `--window`, `--overscan`, `--fps-mode`, `--open-settings`, `--show-fps`, `--force-zero-rwx`, `--fast-forward` / `--no-fast-forward`, `--ui-text-scale`, optional-value `--require-backend [<id>]`) gated on `>= 0.6.1`, backed by `3` new xUnit suites (`148/148` tests across `28` suites in Release & Debug+Automation, `0` warnings) and `Stage2V061ParityProbes`.

### Changed
- **Expressive Controls Presentation & Shared SDK Sync:** Replaced raw `"Schema A/B/C"` labels in `ControlsTabView` and `KeybindsTabView` with expressive titles (`Modern PC (Per-Action)`, `Game 1:1`, `Global 1:1` and readable preset descriptions), updated the bundled Foundation SDK dependency to `v0.5.3` (including `GET /v1/snapshot.png` screenshot support), and consolidated session integration cleanly inside `HostSessionParityHelper`.
- **Non-Quitting `Esc` Precedence:** Updated `Esc` behavior (`HostSessionParityHelper.ApplyNonQuittingEscape`) to strictly follow 4 steps without terminating the host process: cancel active Keybinds capture -> close open `F1` drawer (releasing relative mouse capture) -> pass `Esc` to the game if bound in `perGameModern` -> release relative mouse capture; explicit host exit happens via **`System -> Quit Game`**, window close, or `Alt+F4`.

### Fixed
- **Idle `settings.controls.json` Disk Churn, Demo Cart Audio & Backend/CLI Edge Cases:** Added `SerializeDirtyCheckJson()` comparison in `HostControlTierStore` / `HostSessionParityHelper` to eliminate per-frame idle disk writes to `settings.controls.json`, quieted `--demo-cart` idle audio while keeping clean `60 ms` input chimes, aligned `LauncherArgsHelper` optional `--require-backend [<id>]` and `--rom`/`--disc` normalization + `SyncFlags`, preserved `HostControlTierStore` forward-compatible `[JsonExtensionData]` across saves, and retained `isFpsOverlayEnabled`, `frameRateMode`, `uiTextScale`, and `isCleanCaptureModeEnabled` cleanly in `settings.video.json`.

## [0.6.0] - 2026-11-20

### Added
- **Host Execution Resilience (`BootCrashSentinel`, `MediaRamPreloader`, `ExecutionTierPolicy`):** Added atomic `<dataDir>\booting.sentinel` PID liveness checks that activate in-memory Safe Mode after dirty crashes (disabling `.re*` patches, HD texture packs, and swapping Vulkan/DirectX12 back to OpenGL without modifying saved disk video/audio config) with `--safe-mode-reset` and in-UI recovery, physical-RAM headroom-gated media preloading (`>= 512 MiB` free and `<= 75%` available with `[WARN]` streaming fallback), and Clean-Room AOT tier validation keeping `interpreterOracle` strictly quarantined to CLI invocations.
- **Split-Domain Settings (`SettingsDomainStore` & `HostSettingsStore`):** Migrated runtime configuration into `settings.json` (`v2` core/execution), `settings.video.json`, `settings.audio.json`, and `settings.controls.json` with automatic `v1 -> v2` snapshots (`data\config_history\`), corrupt-file quarantine (`data\quarantine\`), and `.bak`/history recovery across `reEngine.Core`, `reEngine.Host`, and `reEngine.App`.
- **Display Modes, Late-Latch VRR, `21:9` / FMV / HUD Anchors, Color Depth, 8 Live Filters & `F12` Screenshots:** Added `Windowed` / `BorderlessFullscreen` / `ExclusiveFullscreen` + monitor index switching (`Sdl3HostWindow`), `HostFramePacingController` calling `HighResFramePacer.Reset()` on cadence transitions, `21:9 Hor+` + automatic `4:3` FMV centering + HUD anchor zones (`HostViewportGeometry`), 24-bit vs 15-bit + 4x4 Bayer dithering, all 8 live video filters (`nearest`, `bilinear`, `sharpBilinear`, `scanlines`, `crtLite` [`crt-aperture` alias], `lcdGrid`, `xbrz`, `ntscComposite`) in `HostVideoFilterPipeline`, post-present `F12` `HostScreenshotService` (`cleanNative` vs `filteredComposite`), and multi-backend `TryReadSurfaceRect` + `FlushAndSyncForSnapshot` across OpenGL, Vulkan, DirectX 12, ParallelCpu, and Software.
- **Dedicated Audio DSP, Hot-Switched SDL3 Devices, Sound Test Jukebox & 6th `Audio` Tab:** Added 2nd-order Butterworth LP/HP filters (`HostBiquadFilter` + `off`/`crtWarm`/`handheldSpeaker` presets), `HostAudioDspPipeline` (master/BGM/SFX/Voice mix, 5 ms focus-loss mute ramp, `0..200%` stereo width, `linear` vs `sincCubic` resampling, fast-forward audio clamping), zero-restart SDL3 playback device hot-switching (`Sdl3AudioDeviceNative`), `HostSoundTestService` jukebox, extracted `SystemTabView`, updated `F3HudOverlayView` badges, and interactive 6-tab `F1` drawer (`Tab_Audio` slot #2).
- **`>= 0.6.0` Protocol-Gated CLI Routing, WinForms Controls & 4 New xUnit Suites:** Extended `LauncherArgsHelper.ValueOptions` + `RecompLaunchOptionParser` with all v0.6.0 flags (`--preload-media-to-ram` / `--no-preload-media-to-ram`, display, filter, DSP, Safe Mode reset), protocol-gated child routing in `RecompLaunchFlagRouter` (`>= 0.6.0`), added `LibraryDisplayAudioPanel` + Safe Mode badge/reset to `LibraryShelfPanel` and `DetailsRightDrawer`, and added 4 new modular test suites (`135/135` tests across `25` suites in Release & Debug+Automation with `0` warnings).

### Changed
- Scoped sequential milestone roadmap from `v0.6.0 -> v1.0.0` desktop gold (`v2.0.0–v5.0.0` scaffold) across Root Docs and [active.state](active.state).
- Updated `reEngine.Installer` (`LegacyMigrationHelper` preserving all split domain files and `Math.Max(existingSchemaVersion, 1)`) and `build_release.ps1` (`SingleSetup7` layout, `0.6` / `0.5` / `0.4` release retention, verified `SharedLibs\reEngine\v0.6.0\` purity).
- Trimmed `0.3.x` changelog entries (`[0.3.0]`) under Keep a Changelog retention (`0.6`, `0.5`, `0.4`).

### Fixed
- Fixed `HostSessionRunner` frame presentation ordering (`ClearSentinelOnFirstFrame`, pre-snapshot compositor flush), extracted `HostSessionRuntimeBridge`, unified `AppFallbackSettingsStore` directly onto `HostSettingsStore`, and widened `LibraryDisplayAudioPanel` group widths so WinForms labels never clip at desktop DPI.

## [0.5.0] - 2026-11-20

### Added
- **`HostViewportGeometry` & 5-Backend Resize/Aspect Precision:** Centralized aspect-locked viewport calculation across all 5 `HostAspectRatioMode` presets (`nativePar`, `fourByThree`, `squareInteger`, `nativeFit`, `horPlus16By9`), bounded `HostOverscanCrop` source trimming (`overscanCropPx`), `Surface0` (`#0E0E10`) margin clearing, and inverse window-to-content pointer normalization (`TryMapWindowToContentNormalized` on `HostInputFrame`) across `Gl33Presenter`, `VulkanPresenter`, `D3d12Presenter`, `ParallelCpuPresenter`, and `Sdl3HostWindow` / `HostRgbaSurfaceBackend`, plus `--aspect-mode` CLI/settings passthrough and live `SDL_SetWindowFullscreen` transitions (`F11` / `Alt+Enter`).
- **OpenGL FBO Guards & `IHostGraphicsContext` Surface Readback / Pre-QuickSave Sync:** Guarded `Gl33Presenter` against `0x0` minimized framebuffers and incomplete FBOs (`glCheckFramebufferStatus == 0x8CD5`), added optional `OwnerThreadId`, owner-thread-guarded `TryReadSurfaceRect` (`glReadPixels` without Y-flip inversion), and `FlushAndSyncForSnapshot()` on `IHostGraphicsContext`, and wired `HostSessionRunner.DispatchQuickSave` + `Sdl3HostWindow.CloseWindowResources` to flush GPU state strictly prior to `OnQuickSaveRequested()` (`F5`) and presenter teardown.
- **4-Port SDL3 Gamepads, 3-Tier Input (`settings.controls.json`) & Menu Isolation:** Upgraded `Sdl3GamepadProvider` to poll 4 hot-pluggable SDL3 controllers (`PadPorts[0..3]`) with per-port rumble, added `HostControlTierStore` persisting all 3 control tiers (`globalController` / `Global 1:1`, `perGameController` / `Game 1:1`, `perGameModern` / `Modern PC`) in `settings.controls.json` with duplicate and hidden-slot collision validation, wired `_drawer.ControlTierStore` directly to `_inputMapper.ControlTiers`, and enforced Menu `D-Pad` + `Left Stick` navigation isolation independent of Free-Roam bindings.
- **Interactive `F1` Drawer, Hotkeys & Responsive Startup Pump:** Made `F1SettingsDrawerView` (`F1DrawerTabRenderers`), `ControlsTabView`, `KeybindsTabView`, and `F3HudOverlayView` live-interactive via `IHostSessionEventCallbacks` (`OnAspectRatioChanged`, `OnOverscanCropChanged`, `OnFullscreenChanged`, `OnFastForwardChanged`, `OnCutsceneSkipRequested`, `OnQuickSaveRequested`, `OnQuickLoadRequested`, `OnExtraRowActivated`, `OnControlOptionChanged`), mapped `F5`/`F9`/`F11` in `SdlAutomationProxyControl`, and kept SDL event polling responsive during startup and AOT compile waits.
- **3-Way `reCart`/`reCartOne`/`reNes` Alias, `hostProtocolVersion` Routing & `.fds` Parity:** Extended `EngineAliasCatalog` to 3-way `reCart` <-> `reCartOne` <-> `reNes` equivalence, updated `RecompLaunchPlanBuilder.Supports030Routing` and `EngineVersionResolver.IsReadyInstallation` to inspect `hostProtocolVersion >= 0.3.0` and `minSuiteVersion >= 0.3.0` (so `reCart v0.1.0` receives full CLI flags and `.ready` gating), and added `.fds` media discovery parity in both `SuiteMediaTreeWalker` and `RecompPackageReader`.
- **Three New Modular xUnit Suites:** Added `HostViewportGeometryAndPresentersTests`, `HostMultiPortInputAndHotkeysTests`, and `EngineRoutingAndMediaDiscoveryTests` (`117/117` tests passing across `21` suites in Release & Debug+Automation builds with `0` warnings).

### Changed
- Migrated `installer.manifest.json` from `"suiteName": "reEngine"` to canonical `"suiteId": "reEngine"` paired with `Foundation v0.5.2`, split `reEngine.Installer` and `reEngine.Host` helpers into focused modules (`InstallerCliAndAutomation`, `F1DrawerTabRenderers`, `HostInputEvaluationHelper`, `HostMultiBindHelpers`, `HostSessionExtensionsContracts`), and preserved `v0.5.0` `settings.json` keys (`aspectRatioMode`, `overscanCropPx`, `isFastForwardEnabled`) alongside `v0.4.0` keys with `.bak` recovery.
- Updated `Releases\` retention policy to `0.5` / `0.4` / `0.3` and trimmed `0.2.x` changelog history entries (`[0.2.1-hf.1]`, `[0.2.1]`, `[0.2.0]`) to keep the current minor plus 2 prior minor series.

### Fixed
- **Hotfix SemVer Precedence (`-hf.<n>`):** Fixed `SemVer.CompareTo` in `EngineVersionResolver` so `-hf.<n>` hotfixes (`0.3.0-hf.10 > 0.3.0-hf.3 > 0.3.0-hf.1 > 0.3.0 > 0.3.0-rc.1`) strictly outrank stable releases while preserving `.ready` gating for `0.3.0+` and `0.3.0-hf.<n>` leaves and fixing `UpdateCoordinator` hotfix discovery.
- **Launcher `--aspect-mode` Value Normalization:** Registered `--aspect-mode` inside `LauncherArgsHelper.ValueOptions` so mode names like `fourByThree` pass through verbatim instead of being normalized relative to the caller working directory.
- **Resize Stretch, Mid-Frame Snapshot Race & Protocol Gating:** Eliminated window-resize frame stretching across all 5 backends, fixed `HostRgbaSurfaceBackend` mid-frame `PublishSnapshot` racing ahead of `F1`/`F3` overlay draws inside `HostSessionRunner.PresentCompositeFrame`, and fixed pre-`0.3.0` engine version gating dropping CLI options for `hostProtocolVersion >= 0.3.0` child engines.

### Security
- **Dual-Binary Release Fail-Closed Automation Gate & Decoupled Bridge:** Enforced `ExitCode = 2` on `--automation-port` in both Release `reEngine.exe` and Release `reEngine-Setup-v0.5.0-win-x64.exe`, decoupled `IHostAutomationBridge` (`HostSessionOptions.AutomationBridgeFactory`) so `reEngine.Host.dll` carries zero references to `Foundation.Automation` or `System.Windows.Forms`, and added `.fds` to `DecompPipelineCoordinator.ForbiddenCleanRoomExtensions`.

## [0.4.0] - 2026-11-19

### Added
- **Unified `reEngine.Host` Native GPU Presenters, `hdpacks\` & Native Audio (`SDL_AUDIO_DRIVER`):** Implemented native OpenGL 3.3+, Vulkan 1.3+, and DirectX 12 (`directx` / CLI `dx12`) contexts and swapchain presenters via direct OS bindings (without attaching `SDL_CreateRenderer` to GPU windows), deterministic 16px horizontal-band `ParallelCpuPresenter` matching `Software` bit-for-bit at `1x`, path-contained `<dataDir>\hdpacks\` `(clutSha256Hex, rectSha256Hex)` overrides, native OS audio pinning (`wasapi` on Windows set prior to `SDL_InitSubSystem`), `--require-backend` (`ExitCode = 6`), and fullscreen presentation.
- **3-Slot Multi-Bind Input, Xbox/HID Gamepads, Dynamic `ControlOptions` & Touch Contracts:** Added `HostMultiBindRegistry` (3-slot `[1st, 2nd, 3rd]` simultaneous KBM + mouse/wheel `1001..1007`, repeat filtering, single-edge isolation), `Sdl3GamepadProvider` (Xbox & open-standard HID `2001..2032`, `0.15f` deadzone, `0.40f` trigger threshold, rumble), dynamic `ControlOptions` (`ControlsTabView`), interactive 5-column `KeybindsTabView`, and cross-platform `IHostInputProvider` / `HostTouchOverlayView`.
- **Interactive `.decomp` Bring-Up Runner, `SuiteMediaTreeWalker` & Missing-Media Prompt:** Opening `.decomp` files from Windows Explorer now launches the **Bring-Up** shelf pre-loaded with the recipe, `D0..D5` stage picker, automatic suite-tree media discovery (`SuiteMediaTreeWalker`), `MissingMediaPromptDialog` (defaulting to use-in-place with opt-in `.cue`/`.bin` staging into `data\rom\`), and live logs.
- **Standalone `--verify-module` & Frontend `--wait` / `--fullscreen` / `--save-dir` Bridge:** Added `PackageVerificationService` emitting canonical camelCase JSON reports (`--json`, `--require-media`), normalized `--verify-module` selectively in `reEngine.Launcher` while preserving bare engine slugs, and added bounded `<= 3s` graceful `WM_CLOSE` tree teardown in `GracefulProcessTreeShutdown` so saves flush into `--save-dir` before process-tree termination.
- **Canonical `D4_CleanSource` & Expanded Verification:** Switched `DecompD4StrictnessValidator.CanonicalCorpusTiers` to `D4_CleanSource` (keeping `D4_FunctionalRewrite` as a non-double-counted transition alias) and added four modular xUnit suites (`97` total tests across Release & Debug+Automation builds).

### Changed
- Upgraded the `Library` shelf **Backend** dropdown to expose all five Windows backends (`opengl`, `vulkan`, `directx`, `parallelCpu`, `software`), added the **Fullscreen** checkbox and **Verify Package...** action, and aligned all UI/CLI/documentation terminology to static recompilation without emulator framing.
- Updated `reEngine.Installer` to preserve `v0.4.0` keys (`backendId: "directx"`, `isFullscreen`, `audioDriver`, `isHdTexturePackEnabled`) with `.bak` recovery and enforced the 3-MINOR retention policy on `Releases\` (pruning `v0.1.*.7z`, unpacked `v0.2.1`, and `v0.2.1-hf.1`).
- Trimmed `0.1.x` changelog history entries per release retention policy.

### Fixed
- Fixed `LauncherArgsHelper` dropping synchronous execution on `--verify-module`, `--headless`, and `--json`, and fixed `SDL_AUDIO_DRIVER` hint ordering in `Sdl3HostWindow` / `NativeAudioDriverSelector`.
- Fixed `RecompLaunchPlanBuilder` mapping `--require-backend` failures to Exit `1` instead of Exit `6` (`BackendUnavailableException`), and fixed child suite-root derivation when `engines\<id>\v<Ver>` sits two levels below the suite root.
