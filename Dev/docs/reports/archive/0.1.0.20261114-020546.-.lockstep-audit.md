## 1. Executive Summary of Defect
Read-only 3-tier log forensics and isolated `Sandbox\` probes against `reEngine v0.1.0` confirm **five runtime/contract defects** blocking lockstep `0.1.x` integration with `reStation` and `KingsFieldRecomp`:
1. **`P1` — Unhandled `--check-updates` Socket Drop Crash + Empty `"recentLogs": []`:** Offline/refused/reset feed sockets throw an unhandled `HttpRequestException` (`SocketException 10054` / `10061`) out of `RunUpdateCheckCliAsync` to `Program.Main`, crashing with exit code `1` and writing a crash bundle whose `"recentLogs"` array is unconditionally `[]`.
2. **`P1` — Root `reEngine.exe` Async Detach & Missing `--wait` / `--open` Sync Propagation:** Delegating to `Foundation.Launcher.RootLauncherHost.ShouldWaitForChild` causes root `reEngine.exe` to return `0` in `~88–94 ms` without waiting whenever `--test-mode`, `--open`, `--wait`, `--check-updates`, `--register-assoc`, or `--visible-test` is used without `--headless`/`--dry-run` or a positional non-flag `args[0]`, silently masking child crashes (`exit 1`).
3. **`P1` — `RecompLaunchCoordinator` CLI Contract Collision (`--preload-media`) & Unforwarded Flags:** `RecompLaunchCoordinator.SpawnEngineAsync` emits `--preload-media <path>` (rejected with exit code `2` by `reStation v0.1.0` `CliOptions.Parse`, which only recognizes `--disc`), does not accept or forward `--wait` / `--headless` / `--log-dir` / `--config`, and shares `sandbox.DataDirectory` with the launched child engine.
4. **`P2` — Duplicate `[HEARTBEAT]` Prefix in `reengine.log`:** `HeartbeatLogger` prepends `[HEARTBEAT]`, and `Program.cs` passes `line => log("HEARTBEAT", line)`, producing `[HEARTBEAT] [HEARTBEAT]` lines.
5. **`P3` — Single-Engine Update Selection (`FirstOrDefault()`):** `RunUpdateCheckCliAsync` inspects only the first engine returned by `DiscoverInstalledEngines` (sorted descending by version), skipping `0.1.x` patch checks whenever `0.2.0+` is installed side-by-side.

## 4. Root Cause Analysis

1. **Uncaught Offline Network Exceptions & Empty `recentLogs` (`Program.cs#L59-L86, L177-L184`):**
   - `RecompLaunchCoordinator.TryNonBlockingUpdateCheckAsync` wraps `CheckAndStageAsync` in a `try/catch` that logs `[WARN]` (`RecompLaunchCoordinator.cs#L96-L99`), whereas `Program.RunUpdateCheckCliAsync` awaits `coordinator.CheckAndStageAsync(...)` bare (`Program.cs#L177-L183`). Any `HttpRequestException` / `SocketException` / `TaskCanceledException` unwinds into `Program.Main`'s `catch (Exception ex)` (`Program.cs#L80-L86`).
   - Inside that `catch` block, `Program.cs#L83` invokes `CrashBundleService.TryWriteCrashBundle(sandbox.LogDirectory, ReEnginePackagingConstants.AppId, ReEnginePackagingConstants.Version, ex)` without passing the `logLines` queue snapshot (unlike `RegisterGlobalHandlers` at lines `70-74`).
   - Additionally, `reengine.log` emits `timestamp [LEVEL] msg` rather than Standard 15 §5.1 `[v0.1.0] [PID:<pid>/T:<tid>] [component]`, and upstream `Foundation.Core.CrashBundleService` writes `crash_reengine_YYYYMMDD_HHMMSS_fff.json` without `_v<BuildVersion>` or a 20-bundle pruning cap (`CrashBundleService.cs#L129`).

2. **Root Launcher Sync-Wait Bypass (`reEngine.Launcher\Program.cs#L37` -> `RootLauncherHost.ShouldWaitForChild`):**
   - `reEngine.Launcher` delegates directly to `Foundation.Launcher.RootLauncherHost.Run(...)` (`RootLauncherHost.cs#L78-L115`), whose `ShouldWaitForChild` (`RootLauncherHost.cs#L118-L141`) returns `true` only when `--version`, `-v`, `--help`, `-h`, `/?`, `help`, `--headless`, or `--dry-run` appears anywhere, OR when `args[0]` does not begin with `'-'`. Passing `--test-mode` before a positional file, or passing `--open`, `--wait`, `--check-updates`, `--register-assoc`, or `--visible-test`, leaves `isCliOrSyncWait == false` so root `reEngine.exe` returns `0` immediately without propagating `app\reEngine.exe`'s exit code.

3. **`RecompLaunchCoordinator` -> `reStation` CLI Seam & Data Isolation (`RecompLaunchCoordinator.cs#L102-L138`):**
   ```csharp
   psi.ArgumentList.Add("--module");
   psi.ArgumentList.Add(loaded.PackagePath);
   if (!string.IsNullOrWhiteSpace(loaded.PreloadMedia.PrimaryMediaPath))
   {
       psi.ArgumentList.Add("--preload-media");
       psi.ArgumentList.Add(loaded.PreloadMedia.PrimaryMediaPath);
   }
   if (sandbox.TestMode)
   {
       psi.ArgumentList.Add("--test-mode");
       psi.ArgumentList.Add("--data-dir");
       psi.ArgumentList.Add(sandbox.DataDirectory);
   }
   ```
   - `reStation v0.1.0` [`CliOptions.Parse`](<PROJECTS_ROOT>/Personal/reStation/Dev/src/reStation.Core/Core/CliOptions.cs#L61-L126) accepts `--disc <image>` and rejects `--preload-media` (`exit 2`).
   - `RecompLaunchCoordinator` omits `--headless`, `--log-dir`, and `--config`, never parses/forwards `--wait`, and passes `reEngine`'s own `sandbox.DataDirectory` directly to child engines (colliding on `settings.json`).

4. **Duplicate `[HEARTBEAT]` Prefix (`Program.cs#L61,L167,L196`):**
   - `Foundation.Core.HeartbeatLogger` formats `"[HEARTBEAT] {_operationName}: ..."` (`HeartbeatLogger.cs#L75`), and `Program.cs` passes `line => log("HEARTBEAT", line)` where `Log` emits `$"[{level}] {msg}"`.

## 5. Constraints & Architectural Recommendations for `@pland`

1. **`reEngine v0.1.1` Lockstep Patch Scope (Zero Breaking Changes on `0.1.x`):**
   - **Graceful Network Failures + Populated `recentLogs` (`Program.cs` & `UpdateCoordinator.cs`):** Catch `HttpRequestException` / `IOException` / `TaskCanceledException` in `RunUpdateCheckCliAsync` (logging `[WARN]` and returning cleanly instead of throwing crash dumps on offline/dropped sockets); pass `SnapshotRecentLogs()` to `CrashBundleService.TryWriteCrashBundle` in `Program.Main`'s `catch` block; emit single `[HEARTBEAT]` lines (strip/omit redundant `"HEARTBEAT"` wrapper or log under `"INFO"` when forwarding `HeartbeatLogger` lines).
   - **Synchronous Root Wait (`reEngine.Launcher` + `--wait`):** While respecting the read-only `Foundation\` boundary (and logging an upstream proposal to `Foundation\Dev\docs\reports\` if `RootLauncherHost` should also recognize `--wait`/`--check-updates`/`--register-assoc`), ensure `reEngine.Launcher` blocks synchronously and propagates child `ExitCode` whenever `--wait`, `--open`, `--check-updates`, `--register-assoc`, `--headless`, `--dry-run`, `--visible-test`, `--help`, `--version`, or positional package args are supplied anywhere in `args`.
   - **`reStation` Launch Contract Alignment (`RecompLaunchCoordinator.cs`):** Coordinate with `reStation v0.1.1` so `reEngine` emits `--disc` (or both `--disc` / `--preload-media` only once `reStation v0.1.1` accepts `--preload-media` as an alias — emitting `--disc` guarantees compatibility with both `v0.1.0` and `v0.1.1`!), forwards `--headless` / `--log-dir` when specified, isolates child module data under `<dataDir>\modules\<moduleId>\`, and sweeps all installed `(engineId, track)` pairs in `RunUpdateCheckCliAsync` rather than `FirstOrDefault()`.
