Spoke of [`0.2.0.2026-11-14.md`](../plans/0.2.0.2026-11-14.md) and [`ARCHITECTURE.md`](../ARCHITECTURE.md). Keeps all source files `<= 400` LOC (`<= 270` LOC target) and avoids duplicating Standard 00/18/19 lists.

## 1. Suite Directory Layout (`%LOCALAPPDATA%\Programs\StreamItAll\reEngine\`)
Per Wave 0 (`_DevBible v1.5.0`) and Wave 1 (`Foundation v0.4.0`), default non-admin user-scope installation uses:
- **`reEngine\`** — Router app (`reEngine.exe`, `app\reEngine.exe`, `reEngine.Core.dll`, `THIRDPARTY_LICENSES.txt`, `AGENTS.md`).
- **`toolchain\`** — Installed only by the **`Full`** profile: `ghidra\` (Apache-2.0 headless runtime `<= 160 MB`, `GPL/` + `docs/` + Swing UI stripped, SHA-256 verified during build) and `jdk\` (`jlink`-trimmed OpenJDK `GPLv2+CE`), plus `THIRDPARTY_LICENSES.txt`.
- **`engines\re<Platform>\v<Ver>\`** — Side-by-side platform engines (`reStation\v0.2.0\`, `reNes\v0.1.0\`, future `re64`, `reCube`, `reGenesis`).
- **`games\<GameRecomp>\`** — Slim game launchers + clean-room `.recomp` archives (`KingsFieldRecomp\`, `HMBackToNature-Recomp\`, `MetalGearRecomp\`) with preserved `data\rom\`.

## 2. Core Contracts (`reEngine.Core` -> `<SHARED_LIBS>\reEngine\v0.2.0\`)
- **`DecompPackageManifest` (`*.decomp` JSON/ZIP):** Mirrors `RecompPackageManifest` (`moduleId`, `title`, `platformId`, `engineId`, `engineVersion`, `compatibleEngineTrack`, `preloadRomDir`) plus clean-room decomp metadata (`decompSchemaVersion`, `targetDecompTier`, `goalDecompTier`, `packageVersion`, `upstreamResearchPath`, `ghidraProjectName`, `toolchainRequirements`, `recipeEntryPoint`).
- **`IDecompPlatformProvider`:** Interface implemented by platform engines (`reStation`, `reNes`) and discovered under installed `engines\re<Platform>\v<Ver>\`:
  - `PlatformId`, `DisplayName`, `MinimumEngineVersion`.
  - `RunDecompAsync(DecompRunOptions options, CancellationToken ct)` (`D0`–`D5` execution) and `ValidateCleanRoomOutput(string outputDirectory)`.
- **`DecompPipelineCoordinator` & `DecompUnbuiltEngineError` (3-Part Structured Error):** Validates manifest -> locates platform engine (`EngineVersionResolver`) -> delegates to `IDecompPlatformProvider` -> validates clean-room output. When an unbuilt engine is requested (`re64`, `reCube`, `reGenesis`), emits 3-part remediation: `(1)` what failed, `(2)` missing `<engineId>` + `<compatibleEngineTrack>`, `(3)` install `<engineId> >= <engineVersion>` or pass `--engine-dir`.
- **`OfflineToolchainLocator`:** Validates `ghidra\support\analyzeHeadless(.bat)` + `jdk\bin\java(.exe)` + `THIRDPARTY_LICENSES.txt` and enforces `ghidra\GPL\` stripping with zero network calls (`Lightweight` vs `Full`).
- **`AotCacheManager` (`<dataDir>\cache\`):** Indexes `<dataDir>\cache\<moduleId>\<romSha256_16>-<engineId>-<engineVersion>-<moduleVersion>\` with `aot-index.json`, cross-process `.aot-index.lock`, stale-cache eviction, and strict clean-room guard rejecting unexpected `*.Generated.dll` / `*.g.cs` inside `.recomp`.
- **Personal Config Overlay Template:** Ships gitignored `<dataDir>\` local settings override contract + tracked `Dev\settings.example.json` template (zero committed workstation paths/settings).
