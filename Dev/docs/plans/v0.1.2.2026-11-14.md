## 5. Architecture & Technical Design

- **Path Resolution Contract (`RecompPackageReader.ResolveModuleRootDirectory`):**
  ```csharp
  internal static string ResolveModuleRootDirectory(string fullPackagePath)
  {
      ArgumentException.ThrowIfNullOrWhiteSpace(fullPackagePath);
      string full = Path.GetFullPath(fullPackagePath);
      string packageDir = Path.GetDirectoryName(full)
          ?? throw new InvalidOperationException($"Cannot determine module root directory for '{full}'.");
      string trimmedDir = packageDir.TrimEnd(Path.DirectorySeparatorChar, Path.AltDirectorySeparatorChar);
      if (string.Equals(Path.GetFileName(trimmedDir), "app", StringComparison.OrdinalIgnoreCase))
      {
          string? installRoot = Path.GetDirectoryName(trimmedDir);
          string? volumeRoot = string.IsNullOrWhiteSpace(installRoot) ? null : Path.GetPathRoot(installRoot);
          if (!string.IsNullOrWhiteSpace(installRoot) &&
              !string.Equals(installRoot.TrimEnd(Path.DirectorySeparatorChar, Path.AltDirectorySeparatorChar),
                             volumeRoot?.TrimEnd(Path.DirectorySeparatorChar, Path.AltDirectorySeparatorChar),
                             StringComparison.OrdinalIgnoreCase))
          {
              return installRoot;
          }
      }
      return packageDir;
  }
  ```
- **Invariant Preserved:** `DiscoverPreloadMedia(moduleRootDir, manifest)` continues to combine ONLY `moduleRootDir` + `manifest.PreloadRomDir` (`data/rom`), assert containment under `moduleRootDir`, and enumerate disc images without scanning `data\gamedata\`.
